<h1 align="center">TeamFlow</h1>

<p align="center">
  A team collaboration and project management system built with Node.js, Express.js, and MongoDB.
</p>

<h2>Tech Stack</h2>

<ul>
  <li>Node.js & Express.js</li>
  <li>MongoDB & Mongoose</li>
  <li>JWT Authentication</li>
  <li>Joi Validation</li>
  <li>Winston Logging</li>
</ul>

<h2>Features</h2>

<ul>
  <li>User Authentication</li>
  <li>Team Management</li>
  <li>Team Members & Roles</li>
  <li>Role-Based Access Control (RBAC)</li>
</ul>

<h2>Project Status</h2>

<p>
  Backend development is currently in progress. Projects and Tasks are planned for upcoming phases.
</p>
